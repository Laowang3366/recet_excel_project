# 历史文档归档

这里存放已经完成、过期或仅用于追溯的文档。归档文档默认不作为当前实现依据，除非新的任务明确要求回看历史背景。

## 分类

- `audits/`：旧审计报告、旧测试报告、旧 bug 清单。
- `practice-campaign/`：小试牛刀闯关模式早期设计文档包。当前功能已落地，后续以源码和运维记录为准。
- `security/`：早期安全审查拆分文档。当前发布门禁以 `SECURITY.md`、`docs/maintenance/code-review-checklist.md` 和 CI 为准。
- `superpowers/`：历史实现计划和设计规格，保留用于追溯当时的决策。

## 使用原则

- 不在新代码或新流程中直接引用归档文档作为唯一依据。
- 如果归档内容重新变成当前规范，应迁回 `docs/` 或 `docs/maintenance/`，并更新 [文档索引](../README.md)。
